## 2. Composer and references

**Verified.** `Composer` is shared by `/new` and task follow-ups. Its controlled seams support draft text and attachments; it has file selection, paste, and drag/drop intake; it stages accepted attachments while the user types and previews image thumbnails or file-name chips. The textarea supports `/` skill autocomplete and an optional `@` candidate provider. [composer.tsx:L58-L134](../../../packages/web/src/components/composer/composer.tsx#L58) [composer.tsx:L163-L188](../../../packages/web/src/components/composer/composer.tsx#L163) [composer.tsx:L268-L335](../../../packages/web/src/components/composer/composer.tsx#L268) [composer.tsx:L368-L424](../../../packages/web/src/components/composer/composer.tsx#L368) [composer.tsx:L619-L678](../../../packages/web/src/components/composer/composer.tsx#L619)

The task composer persists its text and attachment draft per run, shows diff-comment chips, and handles three run states: queued sends amend the prompt, live runs accept queued messages, and closed/resumable runs can continue. A live run's runner/account/model pills are read-only; continuation can use editable runner/model pills. The composer also exposes quick replies and a stop action when the run is active. ## 6. Design summary

**Verified:** the strongest starting point is the existing task workspace shell and its `session` / `changes` / `files` / `terminal` views. Conversation, run tools, questions, and review actions already have mature components; manager-worker setup and runtime reporting already expose both task-level and sub-agent-level information.

**Design inference:** treat the task workspace as the pane host and make transcript, tool trace, diff/review, terminal, files, task tree, and run inspector independently selectable views. Reuse the existing run/event model, transcript rows, composer seams, diff facade, terminal emulator, and task-tree helpers. Resolve approval events and unified run-tree navigation as explicit design decisions before treating those as existing capabilities.
