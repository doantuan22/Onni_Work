The desktop app starts a local Cezar process and opens its cockpit in a separate window. It supports updates and switching between installed versions. External links open in the system browser.

The app behaves like a desktop app rather than a browser tab: opening it a second time raises the window that is already running, the taskbar/dock badge shows how many tasks the current project is running, and closing the window keeps Cezar running in the tray so agents finish their work.

## Where to find it

Cezar app → version / update menu; tray icon → Open Cezar / Quit

## How to use it

1. Open the installed Cezar app.
2. Work in the cockpit inside its window.
3. Use the version menu to select an installed release.
4. Close the window to leave it running in the tray; pick **Quit** from the tray or the app menu to stop it and its agents.

> **Good to know**: The desktop app and Cezar itself have separate version numbers. Installer availability depends on the operating system and published installation files.
